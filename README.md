# 📄 웹 견적서 작성 프로그램 (EstSheet)

> **서버 설치 없이 브라우저에서 바로 사용하는 스마트 웹 견적서 작성 & 엑셀/PDF 내보내기 솔루션**

웹 견적서 프로그램(EstSheet)은 별도의 설치나 백엔드 서버 없이 브라우저만으로 손쉽게 견적서를 작성하고, 실시간 자동 계산과 엑셀(.xlsx) 저장 및 A4 인쇄를 지원하는 웹 애플리케이션입니다.

---

## 🌟 주요 기능 (Key Features)

- ⚡ **실시간 금액 자동 계산**
  - **수량**과 **단가** 입력 시 **공급가액**이 실시간으로 자동 계산되며 3자리 단위 쉼표(`,`)가 자동으로 적용됩니다.
  - **부가세(VAT) 포함 옵션**: 체크박스 클릭 시 10% 세액이 항목별 및 총 합계에 자동으로 계산되어 반영됩니다.

- 🔤 **한글 금액 자동 변환**
  - 최종 총 합계금액이 숫자(예: `₩ 3,500,000`)와 함께 **한글 금액**(예: `일금 삼백오십만 원정`)으로 자동 변환되어 표기됩니다.

- ⌨️ **편리한 키보드 네비게이션**
  - 방향키(`▲`, `▼`, `◄`, `►`) 및 `Enter` 키를 사용하여 엑셀처럼 항목 입력창 사이를 빠르게 이동할 수 있습니다.
  - 읽기 전용 칸(세액 등)은 자동으로 건너뛰어 속도감 있는 작업이 가능합니다.

- 📊 **스마트 엑셀 (.xlsx) 저장**
  - [ExcelJS](https://github.com/exceljs/exceljs) 라이브러리를 활용하여 웹 작성 내용을 깔끔하게 정돈된 서식의 `.xlsx` 엑셀 파일로 생성 및 다운로드합니다.
  - 별도의 백엔드/로컬 웹 서버 없이 브라우저 단독으로 실행됩니다.
  - 엑셀 파일 다운로드 시 A4 1페이지 맞춤 출력(Fit to Page) 설정이 기본 적용되어 출력 시 편의성을 제공합니다.
  - 파일명이 `수신자명_YYYYMMDD.xlsx` 형태로 자동 저장됩니다.

- 🖨️ **A4 규격 화면 & 인쇄 / PDF 지원**
  - 실제 A4 종이 비율(210mm × 297mm)을 본뜬 WYSIWYG 레이아웃을 제공합니다.
  - 브라우저 인쇄(`Ctrl+P` / `Cmd+P`) 시 조작 버튼 등의 불필요한 요소가 숨겨지고, 깔끔한 A4 1장 견적서/PDF로 출력됩니다.

- 📝 **특기사항 및 공급자 정보 관리**
  - 상호, 대표자, 등록번호, 주소, 업태/종목, 전화번호, 입금 계좌 등 공급자 정보를 손쉽게 편집할 수 있습니다.
  - 하단에 특기사항/참고사항 3줄 입력 칸을 지원합니다.

## 🚀 시작하기 & 사용 방법 (Getting Started)

### 1. 실행하기
별도의 `npm install`이나 서버 실행 없이, 프로젝트를 다운로드한 후 **`index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 열기**만 하면 즉시 사용 가능합니다.

```bash
# 클론 받기
git clone https://github.com/사용자이름/EstSheet.git

# 폴더 이동 후 index.html 브라우저로 열기
cd EstSheet
```

### 2. 견적서 작성 순서
1. **기본 정보 확인 및 수정**: 날짜(오늘 날짜 자동 입력), 수신자 귀하 성함, 공급자 정보(상호/계좌 등)를 확인하거나 수정합니다.
2. **품목 입력**: 품명, 규격, 수량, 단가를 입력합니다. 
   - 입력과 동시에 **공급가액** 및 **총 합계**가 즉시 계산됩니다.
   - 키보드 **방향키**나 **Enter** 키로 셀 간 이동이 가능합니다.
3. **부가세 설정**: 부가세 포함 금액 계산이 필요한 경우 `부가세포함` 체크박스를 활성화합니다.
4. **특기사항 입력**: 견적 유효기간, 납품 조건, 입금 조건 등 특기사항을 작성합니다.
5. **저장 및 인쇄**:
   - 엑셀 파일로 소장하려는 경우 **`엑셀 저장`** 버튼을 클릭합니다.
   - 즉시 출력하거나 PDF로 저장하려는 경우 브라우저 인쇄(`Ctrl+P` 또는 `Cmd+P`)를 실행합니다.

## 💡 주요 키보드 단축키 (Keyboard Shortcuts)

| 키 (Key) | 동작 (Action) |
| :--- | :--- |
| `▲` / `▼` | 위 / 아래 입력 칸으로 이동 |
| `◄` / `►` | 왼쪽 / 오른쪽 입력 칸으로 이동 |
| `Enter` | 아래쪽 입력 칸으로 이동 |
